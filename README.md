# Physics MCQ Practice

https://dmitry-goryunov.github.io/physics_mcq/

https://physicsmcq-ipydxtehmwpfsmntfqgljj.streamlit.app/

A Streamlit quiz app built from a 1,022-question physics MCQ bank. A second,
fully offline version of the same quiz ships as an installable PWA in
[`docs/`](docs) — see [Offline PWA (installable Android app)](#offline-pwa-installable-android-app).

## Features

- Select a physics topic, and either a quiz length or a from/to question range.
- Draw questions only from those not recorded as correct.
- Reveal the source solution with a toggle.
- Record only correct answers; incorrect answers remain unanswered.
- Reset progress separately for each topic.
- Download and restore the correct-answer log as CSV.
- Cloud-safe progress: no shared or temporary server-side log file.
- Progress persists in the browser, so closing and reopening the app on the same device restores it automatically.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Put all files in the root of one GitHub repository.
2. Open `share.streamlit.io` and choose **Create app**.
3. Select the repository and branch.
4. Set the entrypoint to `app.py`.
5. Deploy.

The PDF is about 35 MB. GitHub's website uploader may reject it; use GitHub Desktop or `git push` to add the repository.

## Progress storage

Community Cloud should not be treated as persistent writable file storage. This app therefore encodes completed-question progress in the current URL and also mirrors it to the browser's local storage (via the `streamlit-local-storage` component). When you reopen the app from its base URL on the same device and browser, the saved progress is read back and restored automatically.

Local storage is per-device and per-browser, so it does not follow you to another device or a private/incognito window. For a portable backup, or to move progress between devices, use the **Download CSV log** button and import it elsewhere.

## Offline PWA (installable Android app)

[`docs/`](docs) is a standalone, framework-free rewrite of the same quiz — vanilla
HTML/CSS/JS, no Python or server involved at runtime — that works fully offline
once installed. It renders questions at a higher resolution (4x vs. the live
app's 2x) and ships them as WebP images pre-cropped into question/solution
halves, generated by [`build_offline_assets.py`](build_offline_assets.py).

**Deploy it:**

1. In the repo's GitHub Settings → Pages, set Source to "Deploy from a branch",
   branch `main`, folder `/docs`.
2. Wait for the Pages build, then open the published URL on an Android phone
   in Chrome.
3. Tap **⋮ → Install app** (or use the in-app **Install app** button that
   appears via `beforeinstallprompt`), then open the app once and tap
   **Download for offline use** in the sidebar to cache all ~2,044 images
   (roughly 90 MB). After that it needs no network connection at all.

**Regenerate the assets** (after editing `questions.pdf` or `questions.json`):

```bash
python build_offline_assets.py
```

This rewrites `docs/data/questions.json`, `docs/img/*.webp`, `docs/icons/*.png`,
and `docs/asset-manifest.json` (the file list the service worker/app use to
know what "fully cached" means).

**Progress storage** in the offline app is separate from the Streamlit app —
it lives only in that browser's `localStorage` (key
`physics_mcq_offline_progress_v1`), with the same CSV export/import for
backup and cross-device transfer. There is no URL-based progress token, since
an installed PWA has no shareable per-session URL.
